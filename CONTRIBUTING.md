# Contributing to Google Veo Prompt Collection

Thank you for your interest in contributing! We welcome new prompts and improvements to the collection.

## How to Contribute

### 1. Adding a New Prompt
1.  **Create a new `.txt` file** in the `prompts/` directory. Use a descriptive, snake_case filename (e.g., `Cyberpunk_City_Rain.txt`).
2.  **Add the prompt text** to the file. Keep it concise but detailed as per the [Prompt Engineering Philosophy](README.md#-prompt-engineering-philosophy).
3.  **Update the Featured Prompts table** in `README.md` if you think your prompt is a particularly good example.
4.  **Submit a Pull Request**.

### 2. Improving Existing Prompts
If you find a prompt that can be improved for better results:
1.  Edit the corresponding `.txt` file in `prompts/`.
2.  Submit a Pull Request with a brief explanation of why the change improves the output.

### 3. Adding to the Showcase
If you have a video generated with Veo 3:
1.  Add a new case to `Veo3_Videos.md`.
2.  Include the source link, the prompt used, and the video link (or upload it to the PR).

## Style Guidelines
- **Filenames:** `Descriptive_Name.txt`
- **Prompt Text:** Clear, high-quality, and follows the Subject-Action-Style-Camera recipe.
- **Documentation:** Ensure links in `README.md` are correct.
